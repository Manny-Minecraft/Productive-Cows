## New Features & Additions
* Added native KubeJS Integration. You can now register new Material Cows via server scripts using `ProductiveCowsEvents.registerCows` with a fluent builder syntax (see example on README).
* Added complete parameters setup to KubeJS event.

## Changes & Fixes
* Changed the custom cow JSON datapack directory from `data/<namespace>/material_cows/` to the simpler `data/<namespace>/cows/`.
