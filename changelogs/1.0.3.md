## Before Updating
* **Update client and server together.** The set of registered fluids changed, so a 1.0.3 client cannot join a 1.0.2 server or vice versa.
* **Config file:** settings now live only in `config/productivecows-server.toml`. The old `config/productivecows-common.toml` is no longer read (its values were already being overridden by the server file), so move any custom value to the server file. The `basicCoolerCapacity` and `basicCoolerEnergyCost` options were removed.
* **KubeJS:** cows created without a namespace, like `create('vibranium')`, are now `kubejs:vibranium` as the README always said (they were registered as `minecraft:vibranium`). Cows already saved in your world are migrated automatically, but scripts that used `minecraft:<id>` as a parent must be updated.
* **Datapacks:** cow definitions with a `breed_chance` outside 0 to 1, an unknown fluid or cooling item, or a malformed tag are now skipped, with a warning in the log naming the file and the reason.

## New Features
* **New machine models** in a farm + tech style: wooden pens with hay and iron bars for the Cow Cage and Breeding Cage, glass tanks with ice-cooled caps for the coolers, and a gauge panel with a cow-patterned milk tank for the Milk Generator. They use vanilla textures where possible, so resource packs restyle them too.
* **Fluids look like coloured water**: in the world, inside the coolers, in the machine GUIs and in their buckets, which are now the vanilla bucket filled with the tinted fluid. Being inside a fluid tints the fog with its colour.
* **Milk Generator burns every cow fluid**, not just milk. The rarer the cow, the more it gives: each tier doubles the energy per mB (milk 100 RF/mB, tier 3 800 RF/mB, tier 6 6400 RF/mB) and adds 40 RF/t of output. Vanilla water and lava are not fuels.
* **Reworked JEI pages** with standard slots and animated arrows, plus two new categories: **Milking** (what each cow gives in a Cow Cage) and **Generator Fuel** (energy of each fluid). Press R on a fluid to see which cow makes it, U to see where it is used.
* Clicking a machine's progress bar now opens its JEI recipes (Cow Cage included).
* Milking messages ("not ready to be milked" and similar) now appear above the hotbar instead of in the chat.

## Balance
* `base_yield` in cow definitions now works: it is a percentage of the Cow Cage's 1000 mB per cycle (100 = 1000 mB, range 1 to 800). The built-in cows keep 100.
* The Basic Cooler takes 7 seconds per ingot instead of 5 (`basicCoolerCookTime`, default 140). It needs no energy, as before.
* Calves can no longer go into the Cow Cage or the Breeding Cage.

## Fixes
* Mutations always succeeded: 14 cow definitions used the wrong key names, so their breed chance was ignored. Breeding chances now match the definitions.
* Several cows shared the same pair of parents, so some could never be bred and others came out at random. Zinc, Nickel, Lead, Tin and Enderium now have their own parent pairs.
* The breeding cooldown of captured cows never ran out; it now expires on time and shows the remaining time in the tooltip.
* The Breeding Cage rolled the result twice and could merge different cows in the output slot.
* Hoppers and pipes could pull cows, wheat, buckets and upgrades out of the machines; they now only extract from output slots. Players can take the input bucket back from the Basic Cooler again.
* Capturing a cow kept neither its age nor its breeding cooldown: calves stay calves and adults keep their cooldown.
* The Basic Cooler stopped pushing ingots into the inventory above it while its tank still had fluid.
* Machines no longer send a full network update every tick when connected to pipes and cables, and milked cows no longer send one every tick for 20 minutes. Large farms should run noticeably lighter on servers.
* Fluids for Create, Mekanism and Thermal metals are always registered; their cows load only when the matching mod is installed.
* In singleplayer the machines could use cow definitions left over from the last multiplayer server.
* Energy above 32767 RF was shown wrong in the Milk Generator and Advanced Cooler GUIs, and the Advanced Cooler tooltip showed the wrong energy cost.
* JEI did not show the cooler recipe of cows whose result is an item tag (almost all of them).
* Fluid blocks had no break particles, and Jade's settings showed untranslated names for this mod's options.
* Mooshrooms and other mods' cows were turned into plain cows by the Cow Stick and by right-click conversion.
* Completed the Italian translation and moved the remaining English-only texts to the language files.
* The mod is now declared under the MIT license, matching the repository, and lists JEI, Jade and KubeJS as optional dependencies.
